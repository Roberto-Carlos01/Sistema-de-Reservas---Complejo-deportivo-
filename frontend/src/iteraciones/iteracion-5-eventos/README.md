# 🏆 Iteración 5: Eventos y Servicios Sociales

## Objetivo
Publicar torneos, exhibiciones y clínicas deportivas, gestionar servicios adicionales (arbitraje, fotografía, catering) y registrar inscripciones de clientes.

## Estructura sugerida
- `evento.types.ts`: Tipos para eventos, servicios e inscripciones.
- `evento.api.ts`: Endpoints `GET /api/eventos`, `POST /api/eventos/:id/inscripcion`.
- `EventoCard.tsx`: Tarjeta moderna de presentación de evento.
- `InscripcionModal.tsx`: Formulario de inscripción para torneos o exhibiciones.
