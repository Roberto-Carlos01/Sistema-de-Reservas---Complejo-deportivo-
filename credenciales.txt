============================================
 FLUJO DE PAGOS
============================================

 Métodos de pago disponibles:
   🏢 Presencial      → Reserva confirmada al instante
    Tarjeta Débito  → Requiere comprobante (obligatorio)
   💎 Tarjeta Crédito → Requiere comprobante (obligatorio)
   📱 QR              → Requiere comprobante (obligatorio)

 Para pagos virtuales:
   - Subir comprobante (JPG, PNG, WEBP o PDF, máx 5MB)
   - Ingresar número de referencia (opcional)
   - El admin/empleo verifica desde /verificar-pagos

============================================
📋 ENDPOINTS PRINCIPALES DE LA API
============================================

 Autenticación:
   POST /api/auth/login
   POST /api/auth/registrar

 Canchas:
   GET    /api/canchas
   POST   /api/canchas          (Admin)
   PATCH  /api/canchas/:id      (Admin)
   DELETE /api/canchas/:id      (Admin)

 Reservas:
   POST   /api/reservas
   GET    /api/reservas/mis-reservas
   GET    /api/reservas         (Admin/Empleado)
   PUT    /api/reservas/:id/admitir    (Admin/Empleado)
   PUT    /api/reservas/:id/cancelar

 Pagos:
   POST   /api/pagos/procesar-con-comprobante
   PATCH  /api/pagos/verificar/:id_pago  (Admin/Empleado)
   GET    /api/pagos/pendientes          (Admin/Empleado)
   GET    /api/pagos/historial
   POST   /api/pagos/reintentar/:id_reserva
